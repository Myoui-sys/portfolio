# 💜 Portfólio — Dacyrrôse Melo

Portfólio pessoal desenvolvido para apresentar minha trajetória profissional, habilidades técnicas, experiências e projetos na área de tecnologia.

O projeto reúne trabalhos relacionados a **Desenvolvimento de Software, Desenvolvimento Full Stack, Quality Assurance, Inteligência Artificial, automação de testes e projetos desenvolvidos em hackathons e ideathons**.

Olá! Eu sou **Dacyrrôse Melo**, Desenvolvedora Full Stack formada em **Análise e Desenvolvimento de Sistemas**.

Minha trajetória envolve desenvolvimento web, qualidade de software, análise de requisitos, automação de testes e participação em projetos de inovação.

Este portfólio foi criado para centralizar alguns dos principais projetos e experiências que fazem parte da minha trajetória profissional.

## ⚙️ Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Myoui-sys/portfolio.git
```

### 2. Entre na pasta do projeto

```bash
cd portfolio
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

Depois, abra no navegador o endereço exibido pelo Vite no terminal.

Normalmente:

```text
http://localhost:5173
```
